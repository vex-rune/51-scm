# GPIO 引脚工作模式详解

## 一、内容

- 51 单片机 GPIO 主要有四种工作模式
- 准双向口（最常用，弱上拉）
- 推挽输出（强驱动能力）
- 高阻输入（仅读取，不驱动）
- 开漏输出（需外接上拉电阻）

## 二、要点说明

### 2.1 四种工作模式总览

| 模式 | 驱动能力 | 方向 | 典型应用 |
| :--- | :--- | :--- | :--- |
| **准双向口** | 弱上拉，可吸收大电流 | 输入/输出 | 普通 GPIO、按键、LED |
| **推挽输出** | 强上拉和强下拉 | 仅输出 | 驱动大电流负载 |
| **高阻输入** | 不驱动 | 仅输入 | 读取外部信号、ADC |
| **开漏输出** | 仅强下拉 | 仅输出 | I2C 总线、电平转换 |

### 2.2 准双向口（Quasi-Bidirectional）

| 项目 | 说明 |
| :--- | :--- |
| **别名** | 弱上拉模式、标准 51 模式 |
| **结构** | 内部有**弱上拉电阻**（约 30KΩ） |
| **特点** | 输出高电平时驱动能力弱，输出低电平时能吸收较大电流 |
| **适用** | 大多数普通 GPIO 场景（按键、LED） |
| **配置** | STC 单片机默认模式（PnM0=0, PnM1=0） |

**典型电路**：

```
Vcc
 │
[30KΩ]  ← 弱上拉电阻
 │
 ├──────-> 引脚 P1.0
 │
MOS管   ← 可拉低到 GND
 │
Gnd
```

### 2.3 推挽输出（Push-Pull）

| 项目 | 说明 |
| :--- | :--- |
| **结构** | 上下各有一个 MOS 管，交替导通 |
| **特点** | 输出高电平和低电平均有**强驱动能力** |
| **优点** | 上升沿和下降沿都很陡峭，适合高速切换 |
| **缺点** | 不能实现"线与"功能 |
| **配置** | PnM0=0, PnM1=1 |

**典型电路**：

```
Vcc
 │
MOS管   ← 上拉管（输出高时导通）
 │
 ├──────-> 引脚 P1.0
 │
MOS管   ← 下拉管（输出低时导通）
 │
Gnd
```

### 2.4 高阻输入（High-Impedance Input）

| 项目 | 说明 |
| :--- | :--- |
| **别名** | 浮空输入 |
| **特点** | 引脚**完全不驱动**外部电路，相当于断开 |
| **作用** | 只读取外部信号，不会影响外部电路 |
| **注意** | 读取前必须确保外部有确定电平，否则易受干扰 |
| **配置** | PnM0=1, PnM1=0 |

**适用场景**：
- ADC 模拟信号采集
- 读取外部传感器的数字信号
- 避免影响被测电路

### 2.5 开漏输出（Open-Drain）

| 项目 | 说明 |
| :--- | :--- |
| **结构** | 内部只有下拉 MOS 管，**没有上拉** |
| **特点** | 输出低电平时接地，输出高电平时为**浮空** |
| **必须** | 外接上拉电阻才能输出高电平 |
| **优点** | 可实现"线与"功能，适合多设备共用总线 |
| **配置** | PnM0=1, PnM1=1 |

**典型电路**：

```
Vcc
 │
[外接上拉电阻]  ← 必须外接
 │
 ├──────-> 引脚 P1.0
 │
MOS管   ← 内部下拉管
 │
Gnd
```

### 2.6 模式配置寄存器（STC 新增）

51 单片机有两个模式控制寄存器：`PnM0` 和 `PnM1`，每个端口一组。

| PnM0 | PnM1 | 模式 |
| :--- | :--- | :--- |
| 0 | 0 | **准双向口**（默认） |
| 0 | 1 | **推挽输出** |
| 1 | 0 | **高阻输入** |
| 1 | 1 | **开漏输出** |

**配置示例**（将 P1.0 设置为推挽输出）：

```c
P1M0 = 0x01;  // P1.0 设为推挽
P1M1 = 0x00;
```

### 2.7 四种模式对比

| 对比项 | 准双向口 | 推挽输出 | 高阻输入 | 开漏输出 |
| :--- | :--- | :--- | :--- | :--- |
| 高电平驱动 | 弱 | 强 | 无 | 需外接 |
| 低电平驱动 | 强 | 强 | 无 | 强 |
| 方向 | 输入/输出 | 仅输出 | 仅输入 | 仅输出 |
| 是否需要外接电阻 | 否 | 否 | 否 | **是** |
| 线与功能 | 不支持 | 不支持 | 不支持 | **支持** |
| 速度 | 中 | 快 | - | 中 |

## 三、心得

> 51 单片机的 GPIO 设计比较独特，**准双向口**是它的特色——既能输入又能输出，但上拉能力弱。这意味着：
> 1. 点亮 LED 时通常用**低电平驱动**（灌电流），因为吸收电流能力比输出电流能力强
> 2. 读取按键时配合**外部上拉电阻**会更稳定
> 3. 需要强驱动（如驱动继电器、蜂鸣器）时切换到**推挽输出**
> 4. I2C 等总线协议必须使用**开漏输出**，配合外部上拉电阻才能实现多设备通信
>
> 实际开发中，**80% 的场景使用准双向口就够了**，需要时再切换其他模式。
