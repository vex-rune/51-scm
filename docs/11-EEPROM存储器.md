# 18. EEPROM 存储器

## 18.1 EEPROM 概述

### 18.1.1 简介

**EEPROM**（Electrically Erasable Programmable Read-Only Memory，电可擦写可编程只读存储器）是一种**非易失性存储器**（断电后仍能保留数据），可以多次写入和擦除数据。EEPROM 广泛应用于需要永久存储数据的电子设备中，常用于存储设备工作模式、用户偏好设置等信息。

虽然叫做只读存储器（ROM），但 EEPROM 即可读又可写，这种看似矛盾的命名源于其历史发展。最早期的 ROM 是在制造过程中被一次性编程，出厂之后便只能读取，不能再修改。后期的各种可编程（可写）的 ROM，都是基于最早期的 ROM 发展而来的，所以 ROM 这个名称就被一直沿用下来了。现在的 ROM 基本指非易失性存储器。

本课程使用的 EEPROM 型号是 **AT24C02CN**，其存储容量为 **2K bit**（2048 位，**256 字节**），采用 **I2C 协议**进行读写。

### 18.1.2 引脚功能

| 引脚 | 名称 | 功能 |
|------|------|------|
| 1-3  | A0, A1, A2 | 设备地址选择位（硬件接线决定从机地址） |
| 4    | GND   | 电源地 |
| 5    | SDA   | 串行数据线（双向，开漏，需上拉） |
| 6    | SCL   | 串行时钟线（输入） |
| 7    | WP    | 写保护（接 GND 可正常读写，接 VCC 禁止写） |
| 8    | VCC   | 电源（1.8V ~ 5.5V） |

> **本课程电路**：A0/A1/A2 全部接地，所以 I2C 7 位从机地址 = `0b1010000` = `0x50`。
> 在 I2C 通信时附加 R/W 位，写地址为 `0xA0`，读地址为 `0xA1`。

### 18.1.3 内存结构

AT24C02 的 256 字节存储空间按**页**组织：

```
┌────────────┬──────────────────────────┐
│  页号      │  地址范围                │
├────────────┼──────────────────────────┤
│  Page 0    │  0x00 ~ 0x0F  (16 字节) │
│  Page 1    │  0x10 ~ 0x1F  (16 字节) │
│  Page 2    │  0x20 ~ 0x2F  (16 字节) │
│  ...       │  ...                     │
│  Page 15   │  0xF0 ~ 0xFF  (16 字节) │
└────────────┴──────────────────────────┘
```

- **总容量**：256 字节（2 Kbit）
- **页数**：16 页
- **每页大小**：16 字节
- **地址宽度**：8 bit（0x00 ~ 0xFF）
- **擦写次数**：典型 1,000,000 次
- **数据保持**：> 100 年
- **写周期**：≤ 5 ms（自定时）

### 18.1.4 写操作

AT24C02CN 提供 **Byte Write** 和 **Page Write** 两种写操作模式。

#### 1) Byte Write

Byte Write 用于写入**一个字节**，时序如下：

```
主机发起 START
主机发送：  从机地址(0xA0) + ACK
主机发送：  字地址(0x00~0xFF) + ACK
主机发送：  数据字节 + ACK
主机发起 STOP
                    ↓ 等待 ≤5ms 内部写完成
```

**特点**：
- 每次只能写 1 字节
- 每次写完后需等待约 5 ms（自定时写周期）
- 写期间 SDA/SCL 应保持空闲

#### 2) Page Write

Page Write 用于连续写入**一页数据（最多 16 字节）**，时序如下：

```
主机发起 START
主机发送：  从机地址(0xA0) + ACK
主机发送：  起始字地址 + ACK
主机发送：  数据字节1 + ACK
主机发送：  数据字节2 + ACK
...
主机发送：  数据字节N (N≤16) + ACK
主机发起 STOP
                    ↓ 等待 ≤5ms
```

**注意**：
- **起始地址必须页对齐**（即 `addr % 16 == 0`），否则会发生**回卷**
- 例如：从 `0x0A` 开始写 16 字节，超出 `0x0F` 的部分会**回卷到 `0x00`**
- 一次最多 16 字节，写完需等 5 ms

### 18.1.5 读操作

AT24C02CN 提供了 3 种读操作：Current Address Read、Random Read、Sequential Read。

#### 1) Current Address Read

EEPROM 内部有一个 **Address Register**（地址寄存器），用于记录当前操作（读/写）的字节地址，每当完成一个字节的操作后（读/写），该地址会自动指向下一个字节。

Current Address Read 读取的就是 Address Register 中的地址所指向的这一个字节，时序如下：

```
主机发起 START
主机发送：  从机地址(0xA1) + ACK
从机发送：  数据字节 + NACK
主机发起 STOP
```

**特点**：
- **不需要指定地址**，读取内部计数器当前指向的字节
- 读完后内部地址 +1，可继续读下一个字节
- 适用于不知道地址时的连续读

#### 2) Random Read

Random Read 用于读取**任意指定地址**的一个字节，时序如下：

```
主机发起 START                          ┐
主机发送：  从机地址(0xA0) + ACK        │ Dummy Write
主机发送：  字地址(0x00~0xFF) + ACK     │ 设置内部地址
主机发起 START (Repeated Start)        ┘
主机发送：  从机地址(0xA1) + ACK
从机发送：  数据字节 + NACK
主机发起 STOP
```

**特点**：
- 通过**伪写（Dummy Write）**设置内部地址
- 真正读取的只是 1 个字节
- 读完后内部地址 +1

#### 3) Sequential Read

Sequential Read 用于读取**连续的多个字节**。其起始位置可以是 Address Register 记录的当前地址，也可以是用户指定的任意位置，指定起始位置的方式仍然是在 Sequential Read 前增加一个 Dummy Write 操作。

**从指定位置开始的连续读时序**：

```
主机发起 START                          ┐
主机发送：  从机地址(0xA0) + ACK        │ Dummy Write
主机发送：  字地址 + ACK                │ 设置起始地址
主机发起 START (Repeated Start)        ┘
主机发送：  从机地址(0xA1) + ACK
从机发送：  数据字节1 + ACK
从机发送：  数据字节2 + ACK
...
从机发送：  数据字节N + NACK           ← 最后一个字节发 NACK 结束
主机发起 STOP
```

**特点**：
- 每次读完后内部地址自动 +1
- 主机可以连续读任意多个字节（直到发送 NACK 结束）
- 读到末地址 `0xFF` 后会回卷到 `0x00`

## 18.2 本课程实现

本项目将上述 5 种操作封装在 `src/common/eeprom.c/h` 中。

### 18.2.1 API 列表

| 函数 | 对应操作 | 用途 |
|------|---------|------|
| `EEPROM_ByteWrite(addr, dat)` | Byte Write | 写 1 字节 |
| `EEPROM_PageWrite(addr, buf, len)` | Page Write | 写最多 16 字节 |
| `EEPROM_CurrentAddressRead()` | Current Address Read | 读当前地址字节 |
| `EEPROM_RandomRead(addr)` | Random Read | 读指定地址 1 字节 |
| `EEPROM_SequentialRead(addr, buf, len)` | Sequential Read | 连续读 N 字节 |

### 18.2.2 引脚连接

| 单片机 | AT24C02 |
|--------|---------|
| P1.7   | SCL     |
| P1.6   | SDA     |
| 3.3V   | VCC     |
| GND    | GND     |
| GND    | WP      |

### 18.2.3 串口命令（08-eeprom 项目）

打开串口工具（9600, 8N1）：

| 命令 | 功能 |
|------|------|
| `R<hex>` | 随机读 |
| `W<hex>,<hex>` | 字节写 |
| `P<hex>,<n>,d1,d2..` | 页写（最多 16 字节） |
| `C` | 读当前地址 |
| `S<hex>,<dec>` | 连续读 |
| `T` | 自动测试 5 种方法 |
| `?` | 帮助 |

**示例**：
```
R0x10            → 读 0x10 地址
W0x20,0x55       → 写 0x55 到 0x20
P0x00,3,0x11,0x22,0x33  → 页写 3 字节到 0x00
S0x00,8          → 连续读 8 字节
```

> **重要**：命令末尾必须以**回车换行（`\r\n` 或 `\n`）**结束，单片机才能识别。

## 18.3 应用场景

- **配置参数保存**：保存设备运行模式、校准系数
- **用户偏好设置**：保存亮度、音量、阈值
- **掉电计数**：记录设备启动次数或累计运行时间
- **数据记录**：保存最近的故障日志或采样数据
- **唯一标识**：保存设备序列号
