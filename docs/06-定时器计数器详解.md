# 06 定时器/计数器详解

## 一、概述

STC89C52RC 有 **3 个定时器/计数器**：T0、T1、T2。其中 T0/T1 是标准 8051 配置，T2 是 8052/STC 增强型。

| 定时器 | 位数 | 来源 | 特殊功能 |
|--------|------|------|----------|
| T0 | 16 位 | 标准 8051 | 可拆分为两个 8 位 |
| T1 | 16 位 | 标准 8051 | 常作串口波特率发生器 |
| T2 | 16 位 | 8052/STC 增强 | 捕获、自动重装、波特率发生器、时钟输出 |

**定时 vs 计数**：
- **定时器**：对内部机器周期计数（如 `12MHz / 12 = 1μs` 一个计数）
- **计数器**：对外部引脚脉冲计数（T0 对 P3.4，T1 对 P3.5）

---

## 二、相关寄存器速查

| 寄存器 | 地址 | 可位寻址 | 用途 |
|--------|------|----------|------|
| TCON | 0x88 | 是 | T0/T1 启停控制 + 溢出标志 |
| TMOD | 0x89 | 否 | T0/T1 模式配置 |
| TL0/TH0 | 0x8A/0x8C | 否 | T0 计数低/高字节 |
| TL1/TH1 | 0x8B/0x8D | 否 | T1 计数低/高字节 |
| T2CON | 0xC8 | 是 | T2 控制寄存器 |
| T2MOD | 0xC9 | 否 | T2 模式寄存器（STC 增强） |
| RCAP2L/H | 0xCA/0xCB | 否 | T2 捕获/重装寄存器 |
| TL2/TH2 | 0xCC/0xCD | 否 | T2 计数低/高字节 |

## 三、T0 / T1 的配置

### 3.1 TMOD 寄存器（地址 0x89）

TMOD 高 4 位控制 T1，低 4 位控制 T0，结构完全相同。

**注意**：TMOD **不可位寻址**，不能用 `TMOD_GATE = 1` 这种写法，必须用 `TMOD |= 0x08` 或整体赋值。复位后 TMOD = `0x00`。

```
  Bit:    7      6     5    4      3      2     1    0
        ┌──────┬─────┬─────┬─────┬──────┬─────┬─────┬─────┐
        │ GATE │ C/T │ M1  │ M0  │ GATE │ C/T │ M1  │ M0  │
        └──────┴─────┴─────┴─────┴──────┴─────┴─────┴─────┘
          ←──── 定时器 1 ────->       ←──── 定时器 0 ────->
```

**每个位的详细含义：**

| 位 | 名称 | 归属 | 0 | 1 |
|----|------|------|---|---|
| bit7 | GATE | T1 | 软件启动：`TR1=1` 即计数 | 门控：`TR1=1` **且** `INT1(P3.3)` 为高才计数 |
| bit6 | C/T | T1 | 定时器：对机器周期计数 | 计数器：对 `T1(P3.5)` 引脚下降沿计数 |
| bit5 | M1 | T1 | 见 M1:M0 模式表 | — |
| bit4 | M0 | T1 | 见 M1:M0 模式表 | — |
| bit3 | GATE | T0 | 软件启动：`TR0=1` 即计数 | 门控：`TR0=1` **且** `INT0(P3.2)` 为高才计数 |
| bit2 | C/T | T0 | 定时器：对机器周期计数 | 计数器：对 `T0(P3.4)` 引脚下降沿计数 |
| bit1 | M1 | T0 | 见 M1:M0 模式表 | — |
| bit0 | M0 | T0 | 见 M1:M0 模式表 | — |

**高 4 位和低 4 位完全独立**，改 T0 的配置不会影响 T1，反之亦然。安全写法用位运算只改对应半字节：

```c
/* 只改 T0（低 4 位），不动 T1 */
TMOD &= 0xF0;    // 清空低 4 位
TMOD |= 0x01;    // T0: GATE=0, C/T=0, M1:M0=01（模式1）

/* 只改 T1（高 4 位），不动 T0 */
TMOD &= 0x0F;    // 清空高 4 位
TMOD |= 0x20;    // T1: GATE=0, C/T=0, M1:M0=10（模式2）

/* 设置 GATE=1（开启门控）*/
TMOD |= 0x08;    // T0 门控
TMOD |= 0x80;    // T1 门控
TMOD &= ~0x08;   // 关闭 T0 门控
```

**M1:M0 模式组合：**

| M1:M0 | 模式 | 位数 | 说明 |
|-------|------|------|------|
| `00` | 模式 0 | 13 位 | TH(8位) + TL低5位，兼容 8048 |
| `01` | 模式 1 | 16 位 | TH+TL 全用，最常用 |
| `10` | 模式 2 | 8 位自动重装 | TL 溢出后 TH 值自动装入 TL |
| `11` | 模式 3 | 拆分 | T0 拆两个 8 位；T1 置此模式则停止 |

### 3.2 四种工作模式

| M1:M0 | 名称 | 位数 | 自动重装 | 典型用途 |
|-------|------|------|----------|----------|
| `00` | 模式 0 | 13 位（TH 8位 + TL 低5位） | 否 | 兼容老 8048，基本不用 |
| `01` | **模式 1** | **16 位**（TH+TL 全用） | 否 | **最常用**，精确定时 |
| `10` | 模式 2 | 8 位，TL 计数 + TH 存重装值 | **是** | 串口波特率发生器 |
| `11` | 模式 3 | T0 拆成 2 个 8 位，T1 停 | — | 需要 3 个定时器时 |

### 3.3 模式 1（16 位定时器）— 最常用

```c
/* 配置：T0 模式1，定时，软件启动 */
TMOD &= 0xF0;      // 清 T0 低 4 位，不影响 T1
TMOD |= 0x01;      // 0b00000001 -> GATE=0, C/T=0, M1:M0=01

/* 初值 = 65536 - (定时时间 / 机器周期) */
/* 例：12MHz 晶振，12T 模式，定 50ms */
/* 机器周期 = 12/12MHz = 1μs，计数 50000 次 */
TH0 = (65536 - 50000) / 256;
TL0 = (65536 - 50000) % 256;

ET0 = 1;  // 开 T0 中断
TR0 = 1;  // 启动 T0
```

**溢出时间公式**：

```
溢出时间 = (65536 - 初值) × 机器周期
机器周期 = 12 / 晶振频率(Hz)   (12T 模式)
         =  6 / 晶振频率(Hz)   (6T 模式)
```

### 3.4 模式 2（8 位自动重装）

TL 溢出后，TH 的值自动装入 TL，无需在中断里手动重装。

```c
/* 配置：T1 模式2，定时 */
TMOD &= 0x0F;      // 清 T1 高 4 位
TMOD |= 0x20;      // 0b00100000 -> T1 模式2

/* 例：波特率 9600 @ 11.0592MHz，SMOD=0 */
/* TH1 = 256 - (11059200 / (12 × 32 × 9600)) = 0xFD */
TH1 = 0xFD;
TL1 = 0xFD;

TR1 = 1;           // 启动 T1
```

**优点**：初值只设一次，精度极高，适合产生精确波特率。

### 3.5 模式 3（拆分模式）

T0 拆成两个独立的 8 位定时器：TL0（被 T0 控制位管理）、TH0（借用 T1 的控制位 TR1 和 TF1）。

```
T0 拆分后：
  TL0 -> 8 位定时器（由 TMOD 低4位 + TR0 + TF0 控制）
  TH0 -> 8 位定时器（由 TR1 + TF1 控制）

T1 此时：
  只能工作在不需要中断的场合（如波特率发生器）
  或通过 TR1 手动启动/停止
```

```c
TMOD |= 0x03;      // T0 模式3，拆分

/* TL0 部分：】
TH0 = (256 - 100); // 8 位定时
TL0 = (256 - 100);
ET0 = 1; TR0 = 1;

/* TH0 部分：】
ET1 = 1;           // 借用 T1 的中断使能
TR1 = 1;           // 借用 T1 的启停位
```

### 3.6 TCON 寄存器（控制启停 + 读标志）

```
  Bit:  7    6    5    4    3    2    1    0
       ┌────┬────┬────┬────┬────┬────┬────┬────┐
       │TF1 │TR1 │TF0 │TR0 │IE1 │IT1 │IE0 │IT0 │
       └────┴────┴────┴────┴────┴────┴────┴────┘
```

| 位 | 名称 | 操作 | 说明 |
|----|------|------|------|
| TF1 | T1 溢出标志 | 读/软件清零 | 溢出时硬件置 1 |
| TR1 | T1 启停 | 读写 | 1=启动，0=停止 |
| TF0 | T0 溢出标志 | 读/软件清零 | 溢出时硬件置 1 |
| TR0 | T0 启停 | 读写 | 1=启动，0=停止 |
| IT1/IT0 | 外部中断触发方式 | 见中断文档 | — |
| IE1/IE0 | 外部中断标志 | 见中断文档 | — |

### 3.7 计数器模式

C/T=1 时，对外部引脚脉冲计数（下降沿触发）：

| 定时器 | 外部引脚 |
|--------|----------|
| T0 | P3.4 |
| T1 | P3.5 |

```c
/* T0 计数器模式：对 P3.4 引脚下降沿计数 */
TMOD |= 0x04;      // C/T=1
TH0 = 0;
TL0 = 0;
TR0 = 1;           // 启动计数
```

### 3.8 门控模式（测量脉冲宽度）

GATE=1 时，需同时满足 TRx=1 **且** INTx 为高才计数：

```c
/* 测量 INT0(P3.2) 引脚上的正脉冲宽度 */
TMOD |= 0x09;      // T0: GATE=1, C/T=0, M1:M0=01
TH0 = 0;
TL0 = 0;
TR0 = 1;           // 启动，但需等 INT0 变高才真正计数
/* INT0 变高 -> 开始计数 -> INT0 变低 -> 停止 -> 读出 TH0:TL0 */
```

#### INT0 与 GATE 的关系

GATE 和 INT0 不是同一个东西，但 GATE=1 时它们配合工作：

**各自是什么**

| | GATE (TMOD 的 bit3) | INT0 (P3.2 引脚) |
|---|---|---|
| 本质 | TMOD 寄存器里的一个**配置位** | 芯片的**物理引脚** |
| 作用 | 控制定时器启动条件 | 外部中断输入 / 门控信号输入 |

**三种用法**

| 用法 | 设置 | 效果 |
|------|------|------|
| GATE=0 | `TMOD &= ~0x08` | TR0=1 即计数，INT0 完全不管，可做 GPIO 或外部中断 |
| GATE=1（门控） | `TMOD \|= 0x08` | TR0=1 后还要等 INT0 引脚为高才计数，INT0 变低立即暂停 |
| INT0 作外部中断 | `EX0=1` | 与 GATE 互不干扰，INT0 下降沿/低电平触发 ISR |

**门控时序**

```
       TR0=1（软件 "申请" 启动）
              │
              ├── GATE=0 -> 直接开始计数
              │
              └── GATE=1 -> 等待 INT0 引脚
                            ├── INT0=高 -> 开始计数
                            └── INT0=低 -> 暂停计数
```

**完整测脉冲代码**

```c
/* 测量 P3.2(INT0) 上正脉冲的宽度 */
TMOD |= 0x09;        // GATE=1, C/T=0, 模式1
TH0 = 0; TL0 = 0;
TR0 = 1;             // 定时器 "待命"

while (P3_2 == 0);   // 等脉冲变高 — 定时器自动开始计数
while (P3_2 == 1);   // 等脉冲变低 — 定时器自动暂停

/* 此时 TH0:TL0 × 机器周期 = 脉冲宽度 */
unsigned int width = (TH0 << 8) | TL0;  // 单位：机器周期
```

## 四、T2 的配置（STC 增强型专属）

T2 不使用 TMOD，由 T2CON（0xC8）独立控制。

### 4.1 T2CON 寄存器

```
  Bit:   7    6     5     4     3     2     1     0
        ┌────┬────┬────┬────┬────┬────┬────┬────┐
        │TF2 │EXF2│RCLK│TCLK│EXEN2│TR2│C/T2│CP/RL2│
        └────┴────┴────┴────┴────┴───┴────┴─────┘
```

| 位 | 名称 | 说明 |
|----|------|------|
| TF2 | 溢出标志 | 溢出时硬件置 1，需软件清 0 |
| EXF2 | 外部标志 | T2EX 引脚负跳变时置 1（捕获/重装模式） |
| RCLK | 接收时钟 | 1= T2 作串口接收波特率时钟 |
| TCLK | 发送时钟 | 1= T2 作串口发送波特率时钟 |
| EXEN2 | 外部使能 | 1= 允许 T2EX(P1.1) 引脚触发捕获/重装 |
| TR2 | 启停 | 1=启动，0=停止 |
| C/T2 | 计数/定时 | 0=定时，1=对 T2(P1.0) 引脚计数 |
| CP/RL2 | 捕获/重装 | 1=捕获模式，0=重装模式 |

### 4.2 T2 工作模式

由 `CP/RL2`、`RCLK`、`TCLK` 三个位决定：

| RCLK | TCLK | CP/RL2 | 模式 |
|------|------|--------|------|
| 0 | 0 | 0 | **16 位自动重装** |
| 0 | 0 | 1 | **16 位捕获** |
| 0 | 1 | x | 波特率发生器（仅发送） |
| 1 | 0 | x | 波特率发生器（仅接收） |
| 1 | 1 | x | 波特率发生器（收发都用 T2） |

### 4.3 模式 A：16 位自动重装

```c
/* T2 自动重装模式 @ 11.0592MHz，每 50ms 中断一次 */
T2CON = 0x00;       // CP/RL2=0（重装）, 其他=0
T2MOD = 0x00;       // 默认：递增计数 + 禁止输出
/* 初值：65536 - (50ms / (12/11059200)) = 65536 - 46080 = 19456 */
RCAP2H = (65536 - 46080) / 256;
RCAP2L = (65536 - 46080) % 256;
TH2 = RCAP2H;
TL2 = RCAP2L;
ET2 = 1;            // 开 T2 中断
TR2 = 1;            // 启动 T2
```

> 与 T0/T1 模式 1 不同，T2 溢出后自动从 RCAP2H:RCAP2L 重装，**不需要手动重装**。

### 4.4 模式 B：16 位捕获

T2EX(P1.1) 引脚下降沿触发时，将当前计数值 TH2:TL2 锁存到 RCAP2H:RCAP2L。

```c
/* T2 捕获模式：测量外部脉冲周期 */
T2CON = 0x09;       // CP/RL2=1（捕获）, EXEN2=1（外部使能）
TH2 = 0; TL2 = 0;
RCAP2H = 0; RCAP2L = 0;
TR2 = 1;            // 启动计数
/* P1.1 下降沿到 -> RCAP2H:RCAP2L = TH2:TL2 -> EXF2=1 */
```

### 4.5 模式 C：波特率发生器

```c
/* T2 作波特率发生器，9600 @ 11.0592MHz */
T2CON = 0x34;       // RCLK=1, TCLK=1（收发都用 T2）
RCAP2H = (65536 - (11059200 / (32 * 9600))) / 256;
RCAP2L = (65536 - (11059200 / (32 * 9600))) % 256;
TH2 = RCAP2H;
TL2 = RCAP2L;
TR2 = 1;            // 启动
/* 此时 T1 被释放，可用于其他用途 */
```

### 4.6 可编程时钟输出

T2 的 P1.0 引脚可以输出占空比 50% 的方波（T2OE=1 时）：

```c
/* P1.0 输出 10kHz 方波 @ 12MHz */
T2MOD |= 0x02;      // T2OE=1，使能时钟输出
T2CON = 0x00;       // 自动重装模式
/* 输出频率 = 晶振 / (4 × (65536 - RCAP)) */
/* RCAP = 65536 - 12000000/(4×10000) = 65236 */
RCAP2H = 65236 / 256;
RCAP2L = 65236 % 256;
TR2 = 1;
```

## 五、定时器中断

### 5.1 中断使能

```c
ET0 = 1;   // 开 T0 中断
ET1 = 1;   // 开 T1 中断
ET2 = 1;   // 开 T2 中断（STC 增强）
EA  = 1;   // 开总中断（必须！）
```

### 5.2 ISR 写法

| 定时器 | 中断号 | ISR |
|--------|--------|-----|
| T0 | 1 | `void Timer0_ISR(void) __interrupt(1)` |
| T1 | 3 | `void Timer1_ISR(void) __interrupt(3)` |
| T2 | 5 | `void Timer2_ISR(void) __interrupt(5)` |

### 5.3 完整模板

```c
#include <stc89c52rc.h>

volatile unsigned int tick = 0;

void Timer0_Init(void)
{
    TMOD &= 0xF0;
    TMOD |= 0x01;                // T0 模式1: 16位定时器
    /* 写法一：公式计算（运行时 CPU 算，可读性好） */
    // TH0 = (65536 - 46080) / 256;
    // TL0 = (65536 - 46080) % 256;

    /* 写法二：直接写 16 进制（编译期确定，省指令） */
    /* 65536 - 46080 = 19456 = 0x4C00 */
    TH0 = 0x4C;   // 高8位
    TL0 = 0x00;   // 低8位
    ET0 = 1;
    TR0 = 1;
    EA  = 1;
}

void Timer0_ISR(void) __interrupt(1)
{
    /* 模式 1 需要手动重装 */
    TH0 = (65536 - 46080) / 256;
    TL0 = (65536 - 46080) % 256;
    tick++;
}

void main(void)
{
    Timer0_Init();
    while (1) {
        if (tick >= 20) {   // 20 × 50ms = 1s
            tick = 0;
            P1_0 = !P1_0;   // LED 翻转，1Hz闪烁
        }
    }
}
```

### 5.4 实战：1 秒定时器

**为什么不能直接定 1 秒？** 16 位定时器最多计数 65536 个机器周期。以 12MHz / 12T 为例：

```
最大定时 = 65536 × 1μs = 65.5ms  ← 远远不够 1 秒
```

所以必须用 **"短间隔 + 软件累加"** 的方式：

```
选一个能整除 1 秒的短间隔 -> 进入中断 -> 软件计数到达目标 -> 1 秒到
```

**三种常用方案：**

| 方案 | 基间隔 | 累加次数 | 精度 | 适用场景 |
|------|--------|---------|------|----------|
| 50ms × 20 | 50ms | 20 | 好 | 最常用，整数整除 |
| 10ms × 100 | 10ms | 100 | 好 | 需要同时做其他 ms 级任务 |
| 71ms × 14 | 71ms | 14 | 差（1.006s） | 不推荐，有累积误差 |

**完整代码（50ms × 20 = 1s，11.0592MHz，12T）：**

```c
#include <stc89c52rc.h>

volatile unsigned char sec_flag = 0;   // 1 秒到标志
volatile unsigned char count_50ms = 0; // 50ms 计数器

/* ------------------------------------------------------------
 * 计算过程：
 *   机器周期 = 12 / 11059200 = 1.085μs
 *   50ms 需要计数次数 = 50000 / 1.085 ≈ 46080
 *
 *   模式 1 初值 = 65536 - 46080 = 19456 = 0x4C00
 *     高 8 位 (TH0) = 0x4C
 *     低 8 位 (TL0) = 0x00
 * ------------------------------------------------------------ */
void Timer0_Init(void)
{
    TMOD &= 0xF0;    // 只清 T0 低 4 位
    TMOD |= 0x01;    // T0 模式1: 16位定时器
    TH0 = 0x4C;      // 初值高8位：19456 >> 8 = 76
    TL0 = 0x00;      // 初值低8位：19456 & 0xFF = 0
    ET0 = 1;
    TR0 = 1;
    EA  = 1;
}

void Timer0_ISR(void) __interrupt(1)
{
    TH0 = 0x4C;      // 手动重装初值
    TL0 = 0x00;

    count_50ms++;
    if (count_50ms >= 20) {
        count_50ms = 0;
        sec_flag = 1;   // 1 秒到
    }
}

void main(void)
{
    Timer0_Init();
    while (1) {
        if (sec_flag) {
            sec_flag = 0;
            P1_0 = !P1_0;   // LED 以 1Hz 闪烁
            /* 在这里做每秒一次的任务 */
        }
    }
}
```

**如果要换晶振，只改初值即可：**

| 晶振 | 50ms 计数 | 16 进制初值 | TH0 | TL0 |
|------|----------|------------|-----|-----|
| 11.0592MHz | 46080 | 0x4C00 | 0x4C | 0x00 |
| 12MHz | 50000 | 0x3CB0 | 0x3C | 0xB0 |
| 22.1184MHz | 92160 | — | **超出！** 需换 6T 或减间隔 |

> 22.1184MHz 下 50ms 需要 92160 个机器周期，超过 65536，必须缩小基间隔到 35ms 或开启 6T 模式。

## 六、常见问题与注意事项

### Q1: 定时不准是什么原因？

1. **忘了重装初值** — 模式 1 每次中断必须手动重装 THx/TLx
2. **ISR 执行时间太长** — 超过一次定时周期，导致漏计数
3. **晶振不准** — 实际频率与计算值偏差
4. **中断优先级问题** — 被更高优先级中断抢占，导致重装延迟

### Q2: 最大值能定多久？

| 晶振 | 12T 模式最大定时 |
|------|-----------------|
| 12MHz | 65.5ms（16 位）× 1 = 65.5ms |
| 11.0592MHz | 71.1ms |

要定更长时间，在 ISR 里用软件计数器累加：

```c
volatile unsigned int count = 0;

void Timer0_ISR(void) __interrupt(1)
{
    count++;
}
/* 50ms × 20 = 1s */
```

### Q3: 如何在 ISR 里不做延时？

ISR 里**绝对禁止**调用延时函数。只做最少的事：

```c
/* 错误 */
void Timer0_ISR(void) __interrupt(1)
{
    DelayMs(100);  // ← 卡死！
}

/* 正确 */
void Timer0_ISR(void) __interrupt(1)
{
    flag = 1;      // 仅设置标志位，主循环处理
}
```

### Q4: T0 和 T1 同时用会冲突吗？

不同寄存器，完全独立。但注意三点：

1. **TMOD 是一次写入两个定时器的配置**，修改时用 `&=` / `|=` 避免误改对方
2. **中断号不同**，ISR 互不干扰
3. **模式 3 时** T1 的控制位被 TH0 占用，T1 只能用简单的启停

```c
/* 安全写法：只改 T0，不动 T1 */
TMOD &= 0xF0;   // 清 T0 的低 4 位
TMOD |= 0x01;   // 设 T0 模式 1

/* 安全写法：只改 T1，不动 T0 */
TMOD &= 0x0F;   // 清 T1 的高 4 位
TMOD |= 0x20;   // 设 T1 模式 2
```

### Q5: 12T 和 6T 模式有什么区别？

STC89C52RC 支持两种机器周期模式：

| 模式 | 机器周期 | 同频下速度 | 功耗 | 定时时间 |
|------|---------|-----------|------|---------|
| 12T （传统） | 12 个晶振周期 | 慢 | 低 | 长 |
| 6T （高速） | 6 个晶振周期 | 快 2 倍 | 较高 | 短一半 |

在烧录时通过 STC-ISP 软件选择，不在代码里控制。切换后定时器初值需要重新计算。

### Q6: 看门狗和定时器有什么区别？

| | 定时器 | 看门狗 |
|---|--------|--------|
| 目的 | 产生精确的时间基准/中断 | 防止程序跑飞 |
| 是否需喂狗 | 否 | **是**，超时不喂 = 复位 |
| 能否产生中断 | 是 | 否（直接复位） |
| 寄存器 | TMOD + TCON + TH/TL | WDT_CONTR（0xE1） |

## 七、模式选择速查

| 需求 | 推荐 | 理由 |
|------|------|------|
| 精确 ms 级定时 | T0/T1 **模式 1** | 16 位，灵活 |
| 串口波特率 | T1 **模式 2** | 8 位自动重装，精度高 |
| 无需 CPU 干预的周期定时 | **T2** 自动重装 | 硬件重装，无累积误差 |
| 需要 3 个同时工作的定时器 | T0 **模式 3** | 拆出两个 8 位 |
| 外部脉冲计数 | T0/T1 **计数器模式** | C/T=1 |
| 测量脉冲宽度 | T0/T1 **门控模式** | GATE=1 |
| 测量外部事件时间间隔 | **T2 捕获模式** | 硬件锁存，精度高 |
| 时钟输出 | **T2 时钟输出** | P1.0 可输出方波 |
| 释放 T1 同时用串口 | **T2 波特率发生器** | T1 可解放做别的事 |

## 八、心得

> 定时器是 51 单片机的"心脏"，几乎所有需要精确时序的场景都离不开它。
>
> 1. **模式 1 是主力**：90% 的定时需求用 T0/T1 模式 1 就够了，简单直接
> 2. **模式 2 是串口标配**：自动重装保证波特率零累积误差
> 3. **T2 是锦上添花**：STC 增强型的 T2 功能很强大，但初学时先搞懂 T0/T1
> 4. **中断是定时器的灵魂**：不用中断的定时器没有意义，两者配合才能做实时系统
> 5. **初值计算是基本功**：理解 `65536 - 计数次数` 这个公式，遇到任何晶振频率都能算
>
> 记住一条铁律：**ISR 要短，数据处理放主循环**。
