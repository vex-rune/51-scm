# 第 1 章 I²C 总线

## 1.1 概述

I²C（Inter-Integrated Circuit），通常简称为 IIC，是一种用在集成电路（IC）之间的串行通信总线。它是由 Philips（现在的 NXP 半导体）在上世纪 80 年代开发的，并在之后广泛应用于各种电子设备和嵌入式系统中。

## 1.2 信号线

I²C 为**同步串行**通信，使用两根线路进行通信，分别是数据线（SDA）和时钟线（SCL），SDA 线用于数据传输，SCL 线用于数据传输的同步。SCL 的每个时钟周期，SDA 传输一位数据。

I²C 规定，数据的接收方会在每个时钟周期的**高电平**期间读取数据，具体来讲就是在 SCL 处于高电平时，读取 SDA 上的数据。

因此，SDA 必须在 SCL 低电平期准备好要发送的下一位数据，然后在 SCL 高电平期间保持稳定。

## 1.3 主从架构

I²C 采用主从架构，一个主设备可连接多个从设备。主设备负责发起通信和控制总线，而从设备负责响应主设备的请求。

I²C 总线中的每个设备都有一个唯一的地址（用 7 位二进制数字表示），用于在总线上标识自己。主设备可以根据地址选择性的与特定的从设备进行通信。

需要注意的是，SCL 信号线上的时钟信号始终由**主设备**产生，而 SDA 信号线上的数据信号既可由主设备产生，也可由从设备产生。当主设备向从设备发送数据时，SDA 信号由主设备产生，从设备接收信号；当主设备从从设备读取数据时，SDA 信号由从设备产生，主设备接收信号。

## 1.4 通信协议

### 1.4.1 空闲状态

I²C 协议规定，当 SDA 和 SCL 均为高电平时，总线为空闲状态。

### 1.4.2 起始和结束信号

主设备和从设备间的每次通信，都需要以一个**起始信号**开始，以一个**结束信号**终止。

- **起始信号（S）**：当 SCL 处于高电平时，SDA 由高变低（下降沿）
- **停止信号（P）**：当 SCL 处于高电平时，SDA 由低变高（上升沿）

起始信号和结束信号，都只能由**主设备**产生。

```
空闲 ─┐
      │ S（起始）
SCL ──┐ ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌───────
      └─┘          └─┘          └─┘          └─┘
SDA ────┐
        └──────┐             ┌───────────────────
              P（停止） ─────┘
```

### 1.4.3 确认信号

I²C 协议规定，发送方每发送一个字节（8 位）的数据，接收方都要向发送方回复一个 1 位的确认信号。

- **ACK（第 9 位 = 0）**：接收方已成功接收到该字节，发送方可继续发送下一字节
- **NACK（第 9 位 = 1）**：接收方未能成功接收到该字节，或不希望接收更多数据

```
        ┌──┐ ┌──┐ ┌──┐ ┌──┐ ┌──┐ ┌──┐ ┌──┐ ┌──┐ ┌──┐
SCL ────┘  └─┘  └─┘  └─┘  └─┘  └─┘  └─┘  └─┘  └─┘  └───
        D7  D6  D5  D4  D3  D2  D1  D0  ACK
SDA ────────── 由发送方驱动 ───────┘   └─ 由接收方驱动 ─
```

### 1.4.4 从机地址和读写标识

由于一个 I²C 总线上可能有多个从设备，开始通信前，主设备需要先与目标设备取得联系，再明确本次通信是写还是读。

实现思路：主设备在发送起始信号之后，向总线发送一个字节，前 7 位为目标设备地址，第 8 位为读/写标识（1 = 读，0 = 写）。

```
        ┌──┐ ┌──┐ ┌──┐ ┌──┐ ┌──┐ ┌──┐ ┌──┐ ┌──┐ ┌──┐
SCL ────┘  └─┘  └─┘  └─┘  └─┘  └─┘  └─┘  └─┘  └─┘  └───
        A6  A5  A4  A3  A2  A1  A0  R/W  ACK
SDA ────────── 主设备发送地址+读写位 ──────┘   └ 从机 ─
```

各从设备收到这字节后，将 7 位地址与自身对比：相同则向主设备回复确认信号，不相同则不做任何回应。主设备收到确认信号后，便开始与该设备进行通信。

### 1.4.5 完整通信流程

主设备与某个从设备通信的完整步骤：

1. 发送起始信号（S）
2. 发送目标从设备地址 + 读写标识位
3. 接收从设备回复的确认信号（ACK）
4. 与从设备进行数据传输（发送 / 接收，每字节后跟 ACK / NACK）
5. 发送终止信号（P）

**写数据报文示例**（主设备向地址 0x50 的从机写入 1 个字节 0xAA）：

```
S | 0x50<<1 + W  | ACK | 0xAA          | ACK | P
S   1010 0000         0   1010 1010        0
```

**读数据报文示例**（主设备从地址 0x50 的从机读出 1 个字节）：

```
S | 0x50<<1 + R  | ACK | 0xAA          | NACK| P
S   1010 0001         0   xxxx xxxx       1
```

**复合报文示例**（写寄存器地址后再读，常见于 EEPROM）：

```
S | 0x50+W | ACK | 0x00  | ACK | S | 0x50+R | ACK | data | NACK | P
```
