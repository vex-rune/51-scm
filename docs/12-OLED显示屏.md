# 19. OLED 显示屏

## 19.1 OLED 模块概述

### 19.1.1 OLED 简介

**OLED**（Organic Light-Emitting Diode，有机发光二极管）显示屏由许多微小的发光二极管构成，每个发光二极管就对应着屏幕上的一个像素，通过控制二极管的亮灭就能在屏幕上显示图像或文字。

按照驱动方式划分，OLED 显示屏可分为两类，分别是 **PMOLED**（Passive Matrix，被动矩阵）和 **AMOLED**（Active Matrix，主动矩阵）。

- **PMOLED** 的驱动方式和前文的 LED 点阵类似，每次只能点亮一行或者一列，需要快速的逐行或者逐列扫描来显示内容。
- **AMOLED** 屏幕上的每个像素点都有一个单独的控制电路，可以独立进行控制。

本课程使用的是一块 **PMOLED**（被动矩阵）屏，其分辨率为 **128×64**。

### 19.1.2 驱动芯片

市面上的多数 OLED 显示屏都会带有驱动芯片，驱动芯片的核心作用是控制每个像素点的亮灭以显示图像或文字，此外它还会提供数据接口（例如 I2C），用于接收屏幕上要显示的数据。驱动芯片的存在使得我们可以通过简单的接口控制 OLED 显示屏，大大简化了开发和控制流程。

本课程所使用的这块 OLED 屏的驱动芯片为 **SSD1315**，由于我们需要通过它来控制 OLED 显示的内容，所以需要重点学习它的用法。

#### 19.1.2.1 基本工作原理

SSD1315 通过以下方式工作：
1. MCU 通过 I2C 发送**命令**到 SSD1315（如设置页地址、列地址）
2. MCU 通过 I2C 发送**显示数据**（GDDRAM 内容）到 SSD1315
3. SSD1315 根据 GDDRAM 中的数据自动刷新 OLED 屏幕

#### 19.1.2.2 IIC 接口

虽然 SSD1315 的 MCU Interface 支持多种通信协议（8080、SPI、I2C 等），但我们所选用的 OLED 显示模块只暴露出了 **IIC 接口**。

由于 OLED 显示屏的作用是显示数据，它对于 MCU 来讲更多的是一个**输出设备**，因此我们只需关注如何**向 SSD1315 写入数据**即可。

**写命令时序**：
```
START
发送从机地址(0x78) + ACK      ← SSD1315 I2C 地址
发送控制字节(0x00) + ACK      ← 0x00 = 后续为命令
发送命令字节 + ACK
STOP
```

**写数据时序**：
```
START
发送从机地址(0x78) + ACK
发送控制字节(0x40) + ACK      ← 0x40 = 后续为显示数据
发送数据字节 + ACK
...
STOP
```

> **从机地址说明**：SSD1315 的 7 位 I2C 地址是 `0b0111100` = `0x3C`。
> 加上 R/W 位（写为 0）后是 `0x78`，所以主机发送的地址字节为 `0x78`。

#### 19.1.2.3 GDDRAM

GDDRAM 的作用是存储显示数据，其容量是 **128×64 bit**，每个 bit 对应着屏幕上的一个像素，该 bit 的值就能决定该像素的亮灭。

##### 1) 内存组织结构

```
      COL0  COL1  ...  COL127
Page0 [b0]  [b1]  ...  [b127]    ← 8 bit 组成 1 byte (纵向 8 像素)
Page1 [b0]  [b1]  ...  [b127]    ← 8 bit 组成 1 byte
Page2 [b0]  [b1]  ...  [b127]
...
Page7 [b0]  [b1]  ...  [b127]
```

- GDDRAM 共 **1024 字节**（128 列 × 8 页）
- 每页 **128 字节**，每个字节的 8 个 bit 对应屏幕纵向 8 个像素
- 总像素 = 128 × 8 × 8 = **128 × 64 = 8192 像素**

##### 2) 内存寻址

在了解了内存组织结构之后，我们还需掌握内存的寻址方式，这样才能在我们指定的位置写入指定的内容。

向 GDDRAM 写入数据时是以 **byte** 为单位的，按照上述的内存组织结构，定位一个 byte 至少需要明确两点：**第几页（Page Address，页地址）** 和 **第几列（Column Address，列地址）**。因此 GDDRAM 内部设有两个指针，**Page Address Pointer** 和 **Column Address Pointer**，分别指向当前要写入的页和列。为方便连续写入多个字节，每当成功写入一个字节后，Page Address Pointer 或者 Column Address Pointer 会**自动递增**，指向下一个要写入的位置。

根据指针递增逻辑的不同，GDDRAM 提供了三种不同的寻址方式：**页寻址、水平寻址、垂直寻址**。具体使用哪种模式，可以通过向 SSD1315 发送控制命令进行选择。

下面逐一介绍三种寻址方式的工作原理。

---

###### （1）页寻址

这种寻址方式下，用户需要先向 SSD1315 发送控制命令**设置页地址**（例如 Page1）和**列地址**（例如 COL3），此时 Page Address Pointer 和 Column Address Pointer 就会指向对应的位置。之后便可开始连续发送数据，每成功写入一个字节：

- **Column Address Pointer 会自动 +1**
- **Page Address Pointer 始终不变**
- 如果写到当前页末尾，Column Address Pointer 会**回到当前页的第 1 列**（不切换页）

**设置页地址命令**：`0xB0 | 页号` （如 `0xB0` = Page0, `0xB1` = Page1, ...）

**设置列地址命令**：需要发送两个字节
- `0x00 | (列地址低4位)`  ← 列地址低 nibble
- `0x10 | (列地址高4位)`  ← 列地址高 nibble

例如：列地址 0x23（高 2、低 3）→ 发送 `0x03`、`0x12`

---

###### （2）水平寻址

这种寻址方式下，用户需要先向 SSD1315 发送控制命令，**设置一个写入区域**，具体来讲就是分别指定：

- **页的起始地址和结束地址**（例如 Page1 ~ Page5）
- **列的起始地址和结束地址**（例如 COL2 ~ COL125）

此时 Page Address Pointer 和 Column Address Pointer 会指向该区域的**左上角**。之后便可开始连续发送数据，每成功写入一个字节：

- **Column Address Pointer 自动 +1**，到达目标区域右侧边界时
- **Page Address Pointer 自动 +1**
- 当写到目标区域的右下角时，两个指针会**再次回到左上角**

**设置页地址范围命令**：
```
0x22  ← 命令
起始页(0-7)   ← 参数1
结束页(0-7)   ← 参数2
```

**设置列地址范围命令**：
```
0x21  ← 命令
起始列(0-127) ← 参数1
结束列(0-127) ← 参数2
```

---

###### （3）垂直寻址

这种寻址方式下，用户同样需要先设置一个写入区域，Page Address Pointer 和 Column Address Pointer 指向左上角。之后便可开始连续发送数据，每成功写入一个字节：

- **Page Address Pointer 自动 +1**，到达目标区域底部边界时
- **Column Address Pointer 自动 +1**
- 当写到目标区域的右下角时，两个指针会**再次回到左上角**

> 与水平寻址的区别是：水平寻址按"先行后列"扫描，垂直寻址按"先列后行"扫描。

---

##### 3) 内存 bit 与屏幕像素映射关系

GDDRAM 中的每个 bit 都对应着屏幕上的一个像素，但具体哪个 bit 对应着哪个像素，目前仍是不明确的，最理想的方式当然是每个 bit 和每个像素的位置完全对应，但默认情况下并非如此。

bit 和像素之间的对应关系受两个环节的影响：
1. GDDRAM 和 SSD1315 输出引脚（64 个 COM 和 128 个 SEG）的对应关系
2. SSD1315 的输出引脚和 OLED 屏幕的连线方式

###### （1）GDDRAM 和 SSD1315 输出引脚对应关系

默认情况下，GDDRAM 的 bit 顺序与 SSD1315 的 COM/SEG 引脚的物理排列**不一致**。如果按默认顺序写数据，显示的图像会上下颠倒或左右镜像。

###### （2）SSD1315 输出引脚和 OLED 屏幕对应关系

SSD1315 的 64 个 COM 引脚连接到 OLED 屏幕的行，128 个 SEG 引脚连接到 OLED 屏幕的列。物理连线方式也会影响最终的显示方向。

---

根据前文的描述，若要保证 GDDRAM 中的 bit 与 OLED 屏幕中的像素位置**完全对应**，那么 GDDRAM 和 SSD1315 输出引脚的对应关系需要进行重映射。

**设置 Segment 重映射命令**：`0xA1`（正常显示）/ `0xA0`（左右反置）

**设置 Common 重映射命令**：`0xC8`（正常显示）/ `0xC0`（上下反置）

## 19.2 需求描述

在 OLED 屏指定位置显示 **ASCII 表** 中的指定字符。ASCII 表如下：

| 列号 | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|------|---|---|---|---|---|---|---|---|
| 0    |   |   |   |   |   |   |   |   |
| 1    |   |   |   |   |   |   |   |   |
| 2    |   |   |   |   |   |   |   |   |
| ...  |   |   |   |   |   |   |   |   |
| 7    |   |   |   |   |   |   |   |   |

> **提示**：标准的 8×16 ASCII 字模（每个字符 16 字节）将字符按行排列：
> - 字符宽度：8 像素
> - 字符高度：16 像素（占用 2 页）
> - 字符总数：95（可打印字符，0x20 ~ 0x7E）

## 19.3 关键命令汇总

| 命令 | 命令值 | 说明 |
|------|--------|------|
| 设置显示开关 | `0xAE` / `0xAF` | 关 / 开 |
| 设置页地址 | `0xB0~0xB7` | Page0 ~ Page7 |
| 设置列地址低 4 位 | `0x00~0x0F` | 列地址低 nibble |
| 设置列地址高 4 位 | `0x10~0x1F` | 列地址高 nibble |
| 设置页范围 | `0x22` + 起始页 + 结束页 | 水平/垂直寻址 |
| 设置列范围 | `0x21` + 起始列 + 结束列 | 水平/垂直寻址 |
| 设置寻址模式 | `0x20` + 模式值 | 0=页 1=水平 2=垂直 |
| Segment 重映射 | `0xA0` / `0xA1` | 反置 / 正常 |
| Common 重映射 | `0xC0` / `0xC8` | 正常 / 反置 |
| 反色显示 | `0xA6` / `0xA7` | 正常 / 反色 |
| 整屏点亮 | `0xA4` / `0xA5` | 跟随 RAM / 强制点亮 |
| 设置对比度 | `0x81` + 0x00~0xFF | 默认 0x7F |

## 19.4 本课程实现要点

要在 OLED 上显示 ASCII 字符，需要：

1. **初始化 SSD1315**
   - 关闭显示
   - 设置寻址模式（页寻址）
   - 设置重映射（保证方向正确）
   - 开启显示

2. **设置光标位置**
   - 通过 `0xB0 | 页号` 设置页地址
   - 通过 `0x00~0x0F` 和 `0x10~0x1F` 设置列地址

3. **写入字模数据**
   - 通过 I2C 连续发送 16 字节（8×16 字模）
   - 每写完一个字节，列地址自动 +1
   - 写完 8 字节后切到下一页继续写另外 8 字节
