# 05 STC89C52RC 中断系统详解

## 一、中断基础概念

**中断**是 CPU 与外设通信的一种机制：外设发出中断请求（IRQ）-> CPU 暂停当前任务 -> 执行中断服务程序（ISR）-> 返回继续执行。

```
主程序 ──────────────────────-> 执行中 ──────────────────────-> ...
           ↑                      │                           ↑
           │                      │ 中断触发                   │
           │                      ↓                           │
           │               ┌─────────────┐                   │
           │               │  中断服务程序  │                   │
           │               │   (ISR)      │                   │
           │               └─────────────┘                   │
           └───────────────────────────────────────────┘
                              中断返回
```

**为什么用中断？** 不用轮询等待，CPU 可以干别的事，效率大幅提升。

## 二、STC89C52RC 中断源

### 2.1 中断源一览

STC89C52RC 共有 **6 个中断源**：

| 中断源 | 名称 | 触发方式 | 中断号 | 向量地址 |
|---|---|---|---|---|
| INT0 | 外部中断 0 | 低电平/负边沿 | 0 | 0003H |
| T0 | 定时器 0 溢出 | 溢出时自动触发 | 1 | 000BH |
| INT1 | 外部中断 1 | 低电平/负边沿 | 2 | 0013H |
| T1 | 定时器 1 溢出 | 溢出时自动触发 | 3 | 001BH |
| UART | 串口中断 | 接收/发送完成 | 4 | 0023H |
| T2 | 定时器 2 溢出（STC增强） | 溢出时自动触发 | 5 | 002BH |

> **向量地址**是 CPU 自动跳转的位置，ISR 必须放在对应地址附近（编译器自动处理）。

### 2.2 中断相关寄存器

#### IE（中断使能寄存器，地址 A8H）

```
位:   7     6     5     4     3     2     1     0
名称: EA   -   ET2   ES   ET1   EX1   ET0   EX0
     ┌────┬────┬────┬────┬────┬────┬────┬────┐
     │ EA │ -  │ET2 │ ES │ET1 │EX1 │ET0 │EX0 │
     └────┴────┴────┴────┴────┴────┴────┴────┘
```

| 位 | 名称 | 功能 |
|---|---|---|
| EA | 总中断开关 | 1=开总中断，0=关总中断（**必须置1**） |
| ET2 | 定时器2中断使能 | 1=使能，0=关闭 |
| ES | 串口中断使能 | 1=使能，0=关闭 |
| ET1 | 定时器1中断使能 | 1=使能，0=关闭 |
| EX1 | 外部中断1使能 | 1=使能，0=关闭 |
| ET0 | 定时器0中断使能 | 1=使能，0=关闭 |
| EX0 | 外部中断0使能 | 1=使能，0=关闭 |

#### TCON（定时器控制寄存器，地址 88H）

控制外部中断的触发方式：

```
位:     7      6      5      4      3      2      1      0
名称: TF1    TR1    TF0    TR0    IE1   IT1    IE0    IT0
```

| 位 | 名称 | 功能 |
|---|---|---|
| IT1 | 外部中断1触发方式 | 1=下降沿触发，0=低电平触发 |
| IT0 | 外部中断0触发方式 | 1=下降沿触发，0=低电平触发 |

#### IP / IPH（中断优先级寄存器）

| 寄存器 | 地址 | 说明 |
|---|---|---|
| IP | B8H | 中断优先级低位（1=高优先级，0=低优先级） |
| IPH | BFH | 中断优先级高位（STC 增强） |

IP + IPH 组合成 4 级优先级：

| IPH.x | IP.x | 优先级 | 说明 |
|---|---|---|---|
| 0 | 0 | 0（最低） | 低优先级组 |
| 0 | 1 | 1 | 中优先级组 |
| 1 | 0 | 2 | 高优先级组 |
| 1 | 1 | 3 | 最高优先级 |

## 三、外部中断接线

### 3.1 低电平触发（ITx = 0）

外设输出低电平表示"需要服务"，高电平表示"无事"。

```
        ┌─────────────┐
外设 ────┤ INT0(P3.2) ├───┬── 10kΩ 上拉 -> +5V
        └─────────────┘   │
                          └── 104(0.1µF) 去耦电容 -> GND（可选，消除抖动）
```

**特点**：
- 简单，适合电平传感器（如按键低电平输出、光敏传感器）
- 中断期间外设必须撤除低电平，否则一直触发
- **不需要边沿检测，CPU 随时检测到低电平就进入中断**

### 3.2 下降沿触发（ITx = 1）

外设产生一个下降沿（从高到低）表示"事件发生"，仅触发一次。

**典型应用**：编码器、脉冲计数、外部晶振计数等。

```
外设脉冲 ──-> ┬── INT0(P3.2)
             │
             └── 10kΩ 上拉 -> +5V
```

**特点**：
- 只触发一次，不会重复（除非外设再次发送脉冲）
- 适合计数类应用（外部脉冲计数器）
- 触发后需等待下一个下降沿才会再次触发

### 3.3 触发方式对比

| 特性 | 低电平触发 (ITx=0) | 下降沿触发 (ITx=1) |
|---|---|---|
| 触发条件 | 检测到低电平 | 检测到下降沿 |
| 触发次数 | 持续低电平期间可能多次 | 每个下降沿触发一次 |
| 典型应用 | 按键、传感器、标志位 | 编码器、脉冲计数 |
| 消抖需求 | 需要（RC 滤波） | 可不消抖（边沿已确定） |
| 代码复杂度 | 中断需判断状态 | 纯中断，无需判断 |

## 四、中断服务程序（ISR）

### 4.1 ISR 声明语法（Keil C51 / SDCC 通用）

```c
/*
 * SDCC 语法：
 *   void 函数名(void) __interrupt(中断号) [__using(寄存器组)]
 *
 * 参数说明：
 *   __interrupt  : 中断函数修饰符
 *   中断号        : 0~5，对应向量顺序
 *   __using(n)   : 可选，指定使用的寄存器组（0~3），省略则使用默认寄存器组
 */

// 外部中断 0（INT0），中断号 0
void Int0_ISR(void) __interrupt(0)
{
    /* 中断处理代码 */
}

// 定时器 0 中断，中断号 1
void Timer0_ISR(void) __interrupt(1)
{
    /* 中断处理代码 */
}

// 外部中断 1（INT1），中断号 2
void Int1_ISR(void) __interrupt(2)
{
    /* 中断处理代码 */
}

// 定时器 1 中断，中断号 3
void Timer1_ISR(void) __interrupt(3)
{
    /* 中断处理代码 */
}

// 串口中断，中断号 4
void UART_ISR(void) __interrupt(4)
{
    /* 中断处理代码 */
}

// 定时器 2 中断（STC 增强），中断号 5
void Timer2_ISR(void) __interrupt(5)
{
    /* 中断处理代码 */
}
```

### 4.2 中断号对应关系

| 中断源 | 中断号 | ISR 关键字 | 向量地址 |
|---|---|---|---|
| INT0 | 0 | `__interrupt(0)` | 0003H |
| T0 | 1 | `__interrupt(1)` | 000BH |
| INT1 | 2 | `__interrupt(2)` | 0013H |
| T1 | 3 | `__interrupt(3)` | 001BH |
| UART | 4 | `__interrupt(4)` | 0023H |
| T2 | 5 | `__interrupt(5)` | 002BH |

### 4.3 完整初始化流程

```c
#include <stc89c52rc.h>

/* 全局变量，volatile 修饰防止编译器优化 */
volatile unsigned int timer0_count = 0;

/* 定时器 0 ISR（每 1ms 触发一次） */
void Timer0_ISR(void) __interrupt(1)
{
    /* 重装定时初值（自动重装模式可省略） */
    TH0 = (65536 - 9216) / 256;    /* 12MHz 晶振，12分频，9216次=1ms */
    TL0 = (65536 - 9216) % 256;

    timer0_count++;                  /* 计数器加1 */
    if (timer0_count >= 1000) {
        timer0_count = 0;
        /* 到达1秒，可在此设置标志位 */
    }
}

/* 外部中断 0 ISR（下降沿触发） */
void Int0_ISR(void) __interrupt(0)
{
    /* 边沿触发，只需处理事件 */
    P1_0 = !P1_0;  /* 翻转 LED */
}

void main(void)
{
    /* ── 配置外部中断 0 ── */
    IT0 = 1;       /* 1=下降沿触发，0=低电平触发 */
    EX0 = 1;       /* 开外部中断 0 */

    /* ── 配置定时器 0 ── */
    TMOD &= 0xF0;  /* 清定时器0模式位 */
    TMOD |= 0x01;  /* 模式1：16位定时器 */
    TH0 = (65536 - 9216) / 256;
    TL0 = (65536 - 9216) % 256;
    ET0 = 1;       /* 开定时器0中断 */
    TR0 = 1;       /* 启动定时器0 */

    /* ── 开总中断 ── */
    EA = 1;        /* 必须置1，否则所有中断都不生效 */

    while (1) {
        /* 主循环可以干别的事 */
    }
}
```

### 4.4 ISR 编写规范

**必须遵守：**

1. **尽量简短**：中断里只做最必要的事（如设置标志位、计数器+1），复杂处理放主循环
2. **volatile 修饰全局变量**：被 ISR 修改的全局变量必须加 `volatile`，否则编译器优化后可能出错
3. **避免重入**：8051 没有堆栈保护，ISR 不要调用不可重入的函数（如 `printf`）
4. **中断中不开中断**：除非非常确定不会嵌套，否则不要在 ISR 里 `EA=1`
5. **定时器中断需重装初值**：模式1（16位）不会自动重装，每次中断需手动重装

**错误示例：**
```c
/* 错误：在 ISR 里做延时 */
void Timer0_ISR(void) __interrupt(1)
{
    DelayMs(100);  /* ← 绝对禁止！中断里做延时会卡死其他中断 */
    PrintString("interrupt!");  /* ← 禁止！串口函数可能重入 */
}

/* 正确：只设置标志位 */
volatile unsigned char flag = 0;
void Timer0_ISR(void) __interrupt(1)
{
    flag = 1;  /* ← 只设置标志位，主循环处理 */
}
```

## 五、中断优先级

### 5.1 默认优先级顺序

当多个中断同时发生（或同时挂起）时，CPU 按**默认优先级**顺序响应：

```
优先级从高到低：
INT0 > T0 > INT1 > T1 > UART > T2
中断号:   0    1    2    3    4    5
```

### 5.2 设置高优先级

通过 IP / IPH 寄存器将某个中断设为高优先级：

```c
/* 设置外部中断 0 为高优先级 */
PX0 = 1;   /* IP.0 = 1 */

/* 设置定时器 0 为低优先级（默认） */
PT0 = 0;   /* IP.1 = 0 */

/* 设置串口为高优先级 */
PS = 1;    /* IP.4 = 1 */
```

### 5.3 高优先级可以打断低优先级

```
低优先级 ISR 执行中 ──-> 被高优先级中断 ──-> 高优先级 ISR ──-> 返回 ──-> 继续低优先级 ISR
           ↑                                                   ↑
           └──────────────── 中断嵌套 ────────────────────────┘
```

**重要规则**：
- 高优先级 ISR 可以打断低优先级 ISR
- 同优先级之间按默认优先级排队
- 低优先级 ISR 不能打断高优先级 ISR

### 5.4 优先级配置示例

```c
/* 要求：定时器0优先级最高，串口次之，其他默认 */
void Init_Interrupt_Priority(void)
{
    PT0 = 1;   /* 定时器0高优先级 */
    PS = 1;    /* 串口次高优先级 */
    /* 其他中断保持默认低优先级 */

    EA = 1;    /* 开总中断 */
}
```

### 5.5 优先级寄存器速查表

| 中断 | IP 位 | IPH 位 | 说明 |
|---|---|---|---|
| 外部中断 0 (INT0) | PX0 | PX0H | |
| 定时器 0 (T0) | PT0 | PT0H | |
| 外部中断 1 (INT1) | PX1 | PX1H | |
| 定时器 1 (T1) | PT1 | PT1H | |
| 串口 (UART) | PS | PSH | |
| 定时器 2 (T2) | PT2 | PT2H | |

## 六、实用代码模板

### 6.1 定时器中断模板（1ms 精确定时）

```c
#include <stc89c52rc.h>

volatile unsigned int ms_ticks = 0;

void Timer0_Init(void)   /* 1ms @ 12MHz */
{
    TMOD &= 0xF0;
    TMOD |= 0x01;        /* 模式1: 16位定时 */
    TH0 = (65536 - 1000) / 256;
    TL0 = (65536 - 1000) % 256;
    ET0 = 1;              /* 使能T0中断 */
    TR0 = 1;              /* 启动T0 */
}

void Timer0_ISR(void) __interrupt(1)
{
    TH0 = (65536 - 1000) / 256;
    TL0 = (65536 - 1000) % 256;
    ms_ticks++;
}
```

### 6.2 外部中断模板（按键）

```c
#include <stc89c52rc.h>

volatile unsigned char key_pressed = 0;

void ExtInt0_Init(void)
{
    IT0 = 0;              /* 低电平触发（按键通常为低电平有效） */
    EX0 = 1;              /* 使能INT0 */
}

void Int0_ISR(void) __interrupt(0)
{
    /* 简单防抖：延时后再次确认按键状态 */
    unsigned char i;
    for (i = 0; i < 100; i++);  /* 简单延时消抖（实际应用中建议用定时器） */

    if (P3_2 == 0) {      /* 再次确认低电平 */
        key_pressed = 1;
    }
}
```

### 6.3 串口中断模板

```c
#include <stc89c52rc.h>

volatile unsigned char rx_flag = 0;
volatile unsigned char rx_data = 0;

void UART_Init(void)
{
    SCON = 0x50;          /* 模式1：8位UART，可变波特率 */
    TMOD &= 0x0F;
    TMOD |= 0x20;         /* T1 模式2：自动重装8位定时器 */
    TH1 = 0xFD;           /* 波特率9600 @ 11.059MHz */
    TL1 = 0xFD;
    TR1 = 1;              /* 启动T1 */
    ES = 1;               /* 使能串口中断 */
}

void UART_ISR(void) __interrupt(4)
{
    if (RI) {             /* 接收完成标志 */
        RI = 0;            /* 必须软件清除 */
        rx_data = SBUF;    /* 读取数据 */
        rx_flag = 1;       /* 设置接收标志 */
    }
    if (TI) {             /* 发送完成标志 */
        TI = 0;            /* 必须软件清除 */
    }
}
```

## 七、常见问题

### Q1: 总中断 EA 不置 1 会怎样？

所有单独使能位（ET0、EX0 等）都不生效，CPU 不响应任何中断。

### Q2: 多个中断同时发生，谁先执行？

按默认优先级：`INT0 > T0 > INT1 > T1 > UART > T2`。可以通过 IP/IPH 调整。

### Q3: 定时器中断需要每次重装初值吗？

取决于模式：
- **模式1（16位）**：需要手动重装
- **模式2（8位自动重装）**：只需设置一次，TL 溢出时自动重装 TH 的值

### Q4: 低电平触发时中断一直进入怎么办？

低电平触发会**持续响应**——只要引脚保持低电平，每次中断返回后立即再次进入。解决方法：
1. 改用**下降沿触发**（ITx=1）
2. 在 ISR 里**关闭该中断**（EXx=0），处理完后在主循环重新打开
3. 在 ISR 里读取外设状态寄存器，清除低电平条件

### Q5: SDCC 中 `__interrupt` 关键字在哪里定义？

SDCC 的 `8051.h` 中已定义，不需要额外包含头文件。但需确保使用 `__interrupt(n)` 语法（两个下划线）。

### Q6: ISR 里可以使用 printf 吗？

**不可以**。8051 栈空间极小（约 128 字节），`printf` 涉及大量局部变量和浮点运算，会导致栈溢出。ISR 里只做最小化操作。
