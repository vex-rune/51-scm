# 04 定时器模块封装

## 一、目标

把"定时器中断 + 函数指针数组调度"封装成一个可复用的模块，让用户只关心：

```c
void f1(void) { ... }   // 我的任务
void f2(void) { ... }

void main(void) {
    Timer_Init();
    Timer_Register(f1);   // 注册
    Timer_Register(f2);
    while(1) { ... }      // 主循环干别的
}
// 硬件自动每 2ms 调用一次 f1 和 f2
```

不必再手写 TMOD、TH0、ET0、TR0、ISR。

## 二、架构

```
┌────────────────────┐         ┌──────────────────┐
│  用户代码           │  Register│  定时器模块        │
│  f1(), f2() ...   ├─────────->│  tasks[8]        │
└────────────────────┘         │  ┌────┐┌────┐    │
                                │  │ f1 ││ f2 │... │
                                │  └────┘└────┘    │
                                └──────┬───────────┘
                                       │ 中断
                                ┌──────▼───────────┐
                                │  T0 ISR (2ms)     │
                                │  轮询 tasks[]     │
                                │  调用 enabled 的  │
                                └──────────────────┘
```

## 三、数据结构

```c
typedef void (*Timer_Callback)(void);   // 回调函数类型

#define TIMER_MAX_TASKS  8

typedef struct {
    Timer_Callback func;    // 任务函数指针
    unsigned char  enabled; // 1=运行，0=暂停
} Timer_Task;
```

占用 RAM：8 × 3 = 24 字节（在 512B RAM 里很小）。

## 四、API

| 函数 | 作用 | 返回值 |
|------|------|--------|
| `Timer_Init()` | 初始化 T0 模式1，2ms 中断，清空任务表 | 无 |
| `Timer_Register(func)` | 注册任务，自动启用 | 任务 ID（0~7），失败返回 0xFF |
| `Timer_Enable(id)` | 启动指定任务 | 无 |
| `Timer_Disable(id)` | 暂停指定任务 | 无 |
| `Timer_Unregister(id)` | 从表中移除 | 无 |

## 五、关键设计决策

### 5.1 为什么用函数指针数组而不是链表？

- 51 单片机 RAM 极小（512B），数组更省
- 任务数量固定 8 个足够，覆盖常见 LED 闪烁、PWM、按键扫描等
- 数组遍历在 8 项内极快，中断里跑 8 个空函数 < 50μs

### 5.2 中断里任务函数要短

ISR 中调用任务函数时，硬件**不能嵌套响应新中断**。如果任务里 `DelayMs(1000)` 会卡死。

```c
/* 错误：中断里卡死 */
void f1(void) { DelayMs(1); }

/* 正确：设标志位，主循环处理 */
volatile bit flag;
void f1(void) { flag = 1; }
void main(void) {
    while(1) {
        if(flag) { flag = 0; DoWork(); }
    }
}
```

### 5.3 ID 是数组下标

`Timer_Register` 返回的 ID 就是数组下标 0~7。后续 `Timer_Enable(id)` 拿这个 ID 就能定位。

### 5.4 与 02-display 冲突？

02-display 占用了 T0，04-timer 也占用 T0。两者**不能同时编译到一个工程**。本项目 04-timer 会作为**通用替代**：
- 后续 `05-led-blink-with-timer` 等新项目应改用 04-timer
- 老的 02-display 保持原样，作为示例

## 六、初始化参数

| 参数 | 值 | 说明 |
|------|---|------|
| 定时器 | T0 | 模式 1，16 位 |
| 中断间隔 | 2ms | 8 位数码管扫描需求 |
| 初值 | 0x4C00 (= 65536 - 18432) | 11.0592MHz / 12T |
| 任务数 | 8 | 可改宏 |
