# 04 51 单片机软件开发环境

## 一、内容

- 51 单片机软件开发需要具备 **代码编辑、代码编译、程序烧录** 三大功能
- **Keil** → 代码编辑（集成开发环境 IDE）
- **Keil C51 Compiler** → 代码编译（C 语言编译器）
- **STC-ISP** → 程序烧录（STC 官方工具）
- 三者形成完整开发链路：Keil 写代码 → Keil C51 编译 → STC-ISP 烧录到芯片

## 二、要点说明

### 2.1 51 单片机开发流程

```
┌────────┐    ┌──────────────────┐    ┌──────────┐
│  Keil  │ →  │ Keil C51 Compiler│ →  │ STC-ISP  │
│ 代码编辑│    │    代码编译       │    │ 程序烧录  │
└────────┘    └──────────────────┘    └──────────┘
   编辑 C 代码    编译生成 .hex 文件    写入单片机
```

### 2.2 三大工具对比

| 工具 | 类别 | 主要功能 | 输出 |
| :--- | :--- | :--- | :--- |
| **Keil** | 集成开发环境（IDE） | 代码编辑、仿真、调试 | .c 源代码 |
| **Keil C51 Compiler** | C 语言编译器 | 将 C 代码编译为机器码 | .hex / .bin 文件 |
| **STC-ISP** | 烧录工具 | 将程序写入 STC 单片机 | 烧录到芯片 Flash |

| 项目 | 说明 |

| **平台** | Windows 系统 |

| 项目 | 说明 |

| **标准** | 基于 ANSI C（C89/C90） |

## 三、心得

> 51 单片机开发的"**三件套**"：**Keil（写）+ Keil C51 Compiler（编译）+ STC-ISP（烧录）**。
>
> 1. **Keil** 是 IDE，相当于"代码编辑器 + 工程管理器"，但**它自身不编译代码**
> 2. **Keil C51 Compiler** 才是真正的编译器，**藏在 Keil 内部**，编译时自动调用
> 3. **STC-ISP** 是 STC 芯片烧录专用工具，**其他厂商（如 STM32）用其他工具**
>
> 学习建议：先把 **Keil + STC-ISP** 装好，能跑通"写代码 → 编译 → 烧录 → 看到效果"完整流程，就入门了一半。
